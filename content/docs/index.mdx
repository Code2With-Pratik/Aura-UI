## What's inside

- **Tokens** — colors, borders, easings, and grain, all driven by CSS variables.
- **Components** — Navbar, Hero, Window, Bento, Marquee, Spotlight.
- **Motion** — a single shared cubic-bezier so the whole system moves as one.
